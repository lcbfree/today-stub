# 今日存根 v1 产品原型

这是「今日存根」第一版的移动端 UI 原型，可直接用浏览器打开：

```text
prototype/v1/index.html
```

整页预览图：

```text
prototype/v1/today-stub-v1-prototype.png
```

## 页面清单

1. 今日生成：打开即填写，覆盖今日状态、情绪余额、能量值、三个短文本字段和生成入口。
2. 票根预览：展示完整票根、三套主题入口、保存图片和存入今天。
3. 保存反馈：保存到相册后的底部弹层。
4. 存档墙：按月日历 + 单列票根列表，一天多条记录用叠放票根表达。
5. 存档空态：没有历史记录时引导生成今日存根。
6. 存根详情：查看单张票根、原始字段、再次保存和删除入口。
7. 设置隐私：本地保存说明、清空数据、反馈、版本信息。
8. 授权失败：相册权限被拒绝后的替代路径。

## V1 情绪价值层

这版原型已经加入：

- 今日页顶部候选短语，例如「今天不用解释太多」，并提供「编辑这句」
- 今日状态使用 04 概念图方向的小图标状态卡
- 情绪余额使用带 `-5 / 0 / +5` 的横向刻度
- 能量值使用电池格表达，降低工具表单感
- 「生活痕迹」改为可选模块，可添加睡眠、饮品、小花费、小确幸等
- 票根预览参考 01 小票结构，用 `LIFE TRACE` 分行展示用户选择的模块
- 状态选择后的轻反馈，但明确提示「推荐只做参考」
- 核心自由输入「今天最想留下的一句话」
- 票根红色小印章，例如「今天也算数」
- 票根或页面角落的小物件，例如热茶、晚灯
- 保存成功弹层里的温柔反馈，例如「好了，今天被收好了」

当前原则：模板负责降低门槛，用户写下的话负责让票根变珍贵。

## 视觉方向

- 移动端优先，按微信小程序常见屏幕密度设计。
- 票根是主视觉，不做记账商品明细、金额、支付方式。
- 历史页叫「存档墙」，不做统计、排行或情绪趋势图。
- v1 默认本地保存，设置页明确说明不上传服务器。
- UI 气质参考：`assets/ui-concepts/04-v1-emotional-value-ui-concept.png`。

## 后续落地建议

- 小程序开发时先复刻这套页面结构，再接入真实表单状态。
- Canvas 导出按 `750px` 固定设计宽度实现，内容高度动态计算。
- 本地数据结构预留 `id`、`version`、`createdAt`、`updatedAt`、`syncStatus`。
- 保存相册只在用户点击保存图片时触发授权。
