# Implementation Plan

- [x] 1. 小程序工程与基础配置
- [x] 1.1 初始化原生小程序工程骨架
  - 建立小程序应用入口、页面路由、全局样式和基础窗口配置。
  - 确保今日、预览、存档、详情、设置五个页面可以从开发者工具打开和跳转。
  - 完成后，打开小程序应默认进入今日生成页。
  - _Requirements: 1.1, 8.5_
- [x] 1.2 建立本地配置库和数据契约
  - 配置今日状态、生活模块、短语、小印章、小物件和三套主题。
  - 定义草稿与存根记录的字段约定，包含未来同步预留字段。
  - 完成后，所有默认配置都能通过稳定 ID 查询。
  - _Requirements: 3.1, 4.1, 4.3, 5.2, 7.1_
- [x] 1.3 建立本地存根仓库
  - 支持保存、读取、按月份查询、删除和清空本地存根。
  - 支持同一天多条记录，不以日期作为唯一键。
  - 完成后，新增记录能在本地读取并按日期排序。
  - _Requirements: 1.3, 7.1, 7.2, 7.5, 8.2_

- [x] 2. 今日生成页核心体验
- [x] 2.1 (P) 实现状态、情绪余额和能量值输入
  - 用户可以选择今日状态，调整情绪余额和能量值。
  - 页面视觉延续当前原型中的图标状态卡、横向情绪刻度和能量电池表达。
  - 完成后，选择和调整结果能保存在当前草稿中。
  - _Requirements: 1.1, 2.1, 2.2, 8.5_
  - _Boundary: Today Page, Status Picker, Emotion Meter, Energy Battery_
- [x] 2.2 (P) 实现用户表达与短文本字段
  - 支持填写今天最想留下的一句话、今日证据和可选补充内容。
  - 用户不写自己的句子时，保留候选短语兜底路径。
  - 完成后，用户自己的句子能在生成记录中保持最高展示优先级。
  - _Requirements: 1.2, 1.4, 2.3, 2.4, 2.5_
  - _Boundary: Today Page, Draft Service_
- [x] 2.3 (P) 实现生活痕迹模块编辑
  - 用户可以添加、移除、折叠睡眠、饮品、小花费和小确幸模块。
  - 小花费只收集生活描述，不展示合计、预算、分类或趋势。
  - 完成后，未启用的模块不会进入生成记录。
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5_
  - _Boundary: Life Module Editor_
- [x] 2.4 整合今日生成与复访状态
  - 今日页顶部展示打开轻提示，并在状态选择后展示轻反馈。
  - 用户点击换一句时主动切换候选短语，不自动频繁变化。
  - 当天已有记录时展示可进入当天记录或存档墙的入口。
  - 完成后，只选择状态也能生成结构化存根并进入预览页。
  - _Requirements: 1.2, 1.3, 4.1, 4.2, 4.4_
  - _Depends: 2.1, 2.2, 2.3_

- [x] 3. 票根预览与图片渲染
- [x] 3.1 (P) 实现票根预览组件和三套主题
  - 预览展示日期、编号、状态、情绪、能量、生活痕迹、用户表达、证据、短语、印章和小物件。
  - 支持默认热敏纸、晚间票根和展览门票主题切换。
  - 完成后，预览页能随主题切换即时更新票根视觉。
  - _Requirements: 5.1, 5.2, 5.4_
  - _Boundary: Receipt Preview, Preview Page_
- [x] 3.2 (P) 实现票根布局计算和中文换行
  - 按固定设计宽度计算票根分区、文本换行、生活模块行和动态高度。
  - 长中文内容不溢出，不遮挡关键操作。
  - 完成后，无生活模块、多个生活模块和长句场景都能得到稳定布局。
  - _Requirements: 3.2, 3.3, 5.1, 5.3, 5.4, 8.5_
  - _Boundary: Receipt Layout_
- [x] 3.3 实现 Canvas 图片渲染
  - 将结构化存根和主题绘制成清晰完整的票根图片。
  - 导出内容与预览页字段顺序保持一致。
  - 完成后，预览页可以拿到可保存的临时图片路径。
  - _Requirements: 5.1, 5.3, 6.2, 6.5_
  - _Depends: 3.1, 3.2_

- [x] 4. 保存图片、入档与反馈
- [x] 4.1 实现相册保存和授权失败路径
  - 用户点击保存图片时才触发相册保存相关授权。
  - 授权拒绝、图片生成失败、保存失败都有明确提示和重试入口。
  - 完成后，授权同意时票根图片能保存到相册。
  - _Requirements: 6.1, 6.2, 6.3, 6.5_
  - _Depends: 3.3_
- [x] 4.2 实现保存成功反馈和分享引导
  - 保存成功后展示温柔反馈短语和小物件氛围。
  - 提示用户可以自行发送到微信状态、朋友圈或私聊。
  - 完成后，反馈不承诺一键发布朋友圈。
  - _Requirements: 4.3, 4.5, 6.2, 6.4_
- [x] 4.3 实现生成记录写入本地存档
  - 保存或确认存入今天后，将结构化存根写入本地历史。
  - 写入记录保留短语、印章、小物件、主题和生活模块当次状态。
  - 完成后，新存根能在存档墙查询到。
  - _Requirements: 3.5, 4.5, 7.1_
  - _Depends: 1.3, 4.1_

- [ ] 5. 存档墙、详情与设置
- [ ] 5.1 (P) 实现存档墙
  - 按月份和日期展示本地历史记录，并标记有记录日期。
  - 同一天多条记录用可识别的多条或叠放表达。
  - 完成后，空记录时展示低压力空态并引导生成第一张存根。
  - _Requirements: 7.2, 7.3, 7.6_
  - _Boundary: Archive Page, Stub Card_
- [ ] 5.2 (P) 实现存根详情
  - 展示完整票根、原始字段、已选择生活模块、再次保存和删除入口。
  - 删除前显示确认，确认后从本地历史移除。
  - 完成后，从存档墙点击任一记录可进入对应详情。
  - _Requirements: 7.4, 7.5_
  - _Boundary: Detail Page_
- [ ] 5.3 (P) 实现设置隐私页
  - 展示 V1 本地保存、不上传云端、不要求登录付费的说明。
  - 清空本地数据前二次确认，确认后清空存档墙。
  - 完成后，设置页能清楚表达产品边界且不影响主流程使用。
  - _Requirements: 8.1, 8.2, 8.3, 8.4_
  - _Boundary: Settings Page, Privacy Panel_

- [ ] 6. 跨页面集成与体验收口
- [ ] 6.1 串联今日、预览、存档、详情、设置路由
  - 今日生成进入预览，预览保存后可进入存档，存档进入详情，详情可再次保存。
  - 页面返回时不丢失当前关键状态。
  - 完成后，用户能走完从生成到回看的完整闭环。
  - _Requirements: 1.1, 5.1, 6.2, 7.1, 7.4_
- [ ] 6.2 处理边界状态和失败状态
  - 覆盖无生活模块、长文本、当天多条记录、授权拒绝、记录不存在、本地存储失败。
  - 每个失败状态都保留用户已输入内容或给出可恢复路径。
  - 完成后，核心异常不会导致用户内容直接丢失。
  - _Requirements: 3.3, 5.3, 6.3, 6.5, 7.3, 7.6_
- [ ] 6.3 移动端视觉和文案打磨
  - 对齐现有 V1 原型气质，保持温柔纸张感、状态图标、生活模块和票根层级。
  - 常见手机尺寸下主要文本不遮挡，按钮操作可达。
  - 完成后，页面可读性和操作路径符合静态原型方向。
  - _Requirements: 1.4, 4.6, 5.4, 8.5_

- [ ] 7. 验证与发布前检查
- [ ] 7.1 验证数据和配置稳定性
  - 覆盖配置 ID 查询、生成记录、历史回看、删除和清空流程。
  - 验证历史记录不会因为重新随机短语、印章或小物件而变化。
  - 完成后，关键数据流程有可重复验证结果。
  - _Requirements: 4.5, 7.1, 7.5, 8.2_
- [ ] 7.2 验证票根渲染和保存路径
  - 覆盖三套主题、中文长句、无模块、多模块和小花费模块。
  - 验证导出图片完整、清晰，不出现裁切或记账语义。
  - 完成后，保存到相册的图片与预览主要内容一致。
  - _Requirements: 3.4, 5.1, 5.2, 5.3, 5.4, 6.2_
- [ ] 7.3 完成微信开发者工具手工验收
  - 检查相册授权同意、拒绝、重试路径。
  - 检查今日生成、保存成功、存档空态、详情删除、设置清空。
  - 完成后，V1 主流程可以作为可运行 Demo 给用户试用。
  - _Requirements: 1.1, 1.2, 6.1, 6.3, 7.6, 8.1, 8.5_
