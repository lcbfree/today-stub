# UI 概念图索引

本目录保存「今日存根」前期探索阶段生成的 UI 概念图。

## 图片列表

### 01-life-receipt-desktop-concept.png

用途：

早期「今日生活小票」桌面端概念图。

说明：

这张图偏向「小票生成器」和生活消费记录，包含日期、心情、睡眠、饮品、花费、小确幸等字段。它有视觉参考价值，但产品方向已经调整，不建议作为最终 MVP 的核心方案。

保留原因：

- 可参考左右布局和热敏纸视觉
- 可对比为什么后续要弱化记账感

### 02-today-stub-generator-desktop-concept.png

用途：

新版「今日存根」生成页概念图。

说明：

这张图是当前更接近产品方向的概念：左侧是「把今天留个底」编辑区，右侧是 `TODAY STUB / 今日存根` 票根预览。字段更偏情绪结算，包括今日状态、情绪余额、能量值、今天消耗了什么、今天保留下什么、没有白过的证据、想对今天说一句。

可继续参考：

- 票根的纸张质感
- 情绪结算区块
- 红色日期印章
- 主题选择区
- 「这一天，允许被保存」作为最终判定文案

### 03-archive-wall-mobile-concept.png

用途：

小程序「存档墙」历史记录页概念图。

说明：

这张图展示历史日期的数据如何呈现：顶部月份切换，中间轻量月历，有记录日期用小点标记，下方是单列票根列表。一天多条记录用叠放票根和「今日存根 x 3」表达。

可继续参考：

- 移动端单列票根墙
- 历史记录不是统计报表，而是票根盒子
- 底部 Tab：今日 / 存档
- 纸张、孔洞、印章、植物线稿等细节

### 04-v1-emotional-value-ui-concept.png

用途：

V1 情绪价值增强版 UI 概念图。

说明：

这张图展示「今日存根」第一版在原有生成、预览、保存闭环上，加入随机治愈短语、小印章、小物件和保存成功反馈之后的整体气质。它更接近当前 v1 的目标：女性用户友好、温柔、有纸张纪念物感，但不做幼稚可爱风或心理咨询感。

可继续参考：

- 今日生成页顶部的随机短语
- 状态选择里的小图形提示
- 票根上的红色小印章
- 票根角落的小物件
- 保存成功弹层里的温柔反馈

注意：

这张图用于气质参考，图中具体文案和控件结构不作为开发唯一依据。开发时以 `docs/product.md` 和 `prototype/v1/` 为准。

## 使用建议

后续正式设计时，建议以 `04-v1-emotional-value-ui-concept.png`、`02-today-stub-generator-desktop-concept.png` 和 `03-archive-wall-mobile-concept.png` 为主，`01-life-receipt-desktop-concept.png` 只作为反面边界和早期视觉参考。
