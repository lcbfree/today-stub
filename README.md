# 今日存根

这是「今日存根」小程序的新项目资料目录。

本项目从 `/Users/changbo.liu/project/plugin-tools` 中迁移了当前阶段的产品探索文档和 UI 概念图，方便后续在这里继续做小程序原型、视觉打磨和 MVP 开发。

## 产品一句话

「今日存根」是一个轻量情绪记录小程序，帮用户用 30 秒把今天生成一张漂亮的生活票根，作为今天存在过、努力过、没有白过的证据。

## 当前产品判断

第一版建议做成微信小程序，而不是独立 App 或复杂网站。

第一版坚持：

- 不登录
- 不支付
- 不做公开社区
- 不依赖后端
- 本地保存历史记录
- 保存票根图片到相册

第一版 v1 同时加入轻量情绪价值层：

- 随机治愈短语
- 今日小印章
- 今日小物件
- 模块化生活痕迹：睡眠、饮品、小花费、小确幸等可选模块
- 保存成功后的温柔反馈

第一版主流程：

1. 用户选择今日状态，写下最想留下的一句话
2. 按需添加睡眠、饮品、小花费、小确幸等生活痕迹
3. 生成一张「今日存根」
4. 保存到相册
5. 存入本地「存档墙」

## 下一步建议

1. 先把小程序信息架构定下来：`今日`、`存档`、`详情/预览`、`设置`。
2. 先做可运行 Demo，重点验证 Canvas 导出、中文换行、保存相册。
3. 再打磨视觉主题，优先做好「今日生成页」和「存档墙」。
4. 后续如果做云版本，按文档里的 `syncStatus` 迁移策略把本地历史同步到云端。
